# z5_snubhex/ — (3,3,3,3,6) snub hexagonal 档案

> 2026-10-01 建档(11 型均匀顶点型全表归档,第七十五轮)。
> (3,3,3,3,6) = 11 种阿基米德均匀顶点型之一;z=5 全有理面族 {3,6}。

## 结论(2026-09-27 第二十一轮定案)

**dim_ℝ = dim_ℚ = 1(精确,k=1..5)⟹ 刚性,Ω ≤ k,s(∞) = 0。**
机制 = 共边三角形直接锁死(比 3.4.6.4 的经方间接锁更强);构造 = 三角格完全码
ker φ(i,j) = (i+3j) mod 7。详见 `SNH_刚性定理.md`。
