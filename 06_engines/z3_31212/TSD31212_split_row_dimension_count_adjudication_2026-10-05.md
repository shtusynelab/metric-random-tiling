## 二、机制分解:劈行后两子系统解耦,熵住在中段边

劈行(每行按有理部/√3 部拆)后,约束按边类型分块,两个子系统**无公共变量**:

- **cut 子系统**(截角边,6L² 条,方向 = 60° 网):每三角形 3 边劈行后强制相等
  (三角形锁死,秩 2)⟹ 收缩成 2L² 个类;剩余方程 = 每十二边形 2 条截角位。
  **dim_cut = 3L−1(线性,亚广延)** ⟹ s_cut ≤ (3L−1)ln 2/(3L²) → 0(定理级)。
- **mid 子系统**(中段边 = 蜂窝边中段,3L² 条,方向 = 30° 奇数倍):无先验收缩,
  方程 = 每十二边形 2 条(和规则型,二值下即 ℓ0+ℓ1 = ℓ3+ℓ4、ℓ1+ℓ2 = ℓ4+ℓ5)。
  **dim_mid = L²+2(二次,广延)⟹ 熵只能住在这里**。

恒等式 dim_ℚ = dim_cut + dim_mid = (3L−1) + (L²+2) 全六点成立。
方向语义更正(与直观相反):中段边方向 = 30° 奇数倍(cos = ±√3/2 属 √3 部、
sin 有理),截角边方向 = 60° 网(cos 有理、sin = ±√3/2 属 √3 部)——由 L=1
行内容调试确认。审稿人 R1 的"劈行后裂解为交替边子集的和规则约束"预言:分块
结构命中;"三角形扇区二值刚、三值可能广延"需按计数判定(见 §三/§四)。
