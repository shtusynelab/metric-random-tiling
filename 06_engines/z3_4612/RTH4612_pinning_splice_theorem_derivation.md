## 一、设定与记号

4.6.12 等角密铺的环面商 T(W,L):格 ⟨W·T₁, L·T₂⟩,T₁=(2,0)、T₂=(1,√3)。
**环面周期是 W·T₁ 与 L·T₂**(T₁ 是半格——实现教训:圈查找的 BFS 目标
位移必须用 W·T₁/L·T₂)。类变量 = 方形对边等式收缩后的 SD/SH/HD 类,
|C| = 12WL;约束 = 面局域齐次线性方程(每面 2 条独立,PAIR_COS/SIN 系数),
秩 8WL−4,dim = 4WL+4。两值计数 Ω(W,L) = #{x ∈ {0,1}^C : Ax = 0};
A·1 = 0(每面系数和为零)⟹ 补移位 x ↦ 1−x 是解空间的自由轨道。
字母表约定:{0,1} 计数 = 任意两值字母表(齐次线性缩放/平移双射)。

## 二、钉扎定义

**定义**。T₂p-同伦边圈 = 原生边首尾相接的闭合路径,提升位移 L·T₂
(绕长向一周),且商像边两两不同、从商图删除后连通(非分离:割开成柱面)。
n₀(W,L) = Sol(W,L) 中钉扎圈类(圈像商边所属类)全取 0 的解数。
λ₀*(W) = limsup_{L→∞} (1/L) ln n₀(W,L)。

## 三、钉扎拼接定理

**定理**。Ω(W₁+W₂, L) ≥ n₀(W₁, L)·n₀(W₂, L)。

**证明**。G = (W₁+W₂)×L 沿两条不交平行 **T₂p-同伦**边圈 C₁、C₂
(沿 T₁ 方向相距 W₁·T₁)切成柱面带 P₁(宽 W₁,周向 T₂p)、P₂(宽 W₂)。
给定 x_i ∈ Sol(W_i, L) 且钉扎圈类 = 0:

(1) *投影*。W_i×L 环面沿其 T₂p 钉扎圈割开 = 柱面 P_i;x_i 逐边映上,
钉扎类在两边界同取 0。
(2) *拼合*。G 赋值:P₁ 块按 x₁、P₂ 块按 x₂,圈边取 0(两侧一致)。
(3) *面方程逐字转移*。圈沿边走 ⟹ 每个面完整落在一带内;对应面同几何
⟹ 同系数;钉扎边值同 0 ⟹ 方程成立。
(4) *类融合无冲突*。跨圈方形对边等式把圈边与两侧块内边并类,两侧值都
是钉扎 0 ⟹ 融合类单值。
(5) *单射*:块内限制恢复 x_i。∎

**迭代推论**。Ω(W, L) ≥ n₀(2, L)^⌊W/2⌋(W = 2m+r),于是

  liminf_{W→∞} lim_{L→∞} ln Ω(W,L)/(6WL) ≥ λ₀*(2)/12。

**为什么需要钉扎(不可用普通 superadditivity)**:λ(W)/(6W) 由 Fekete
递减于 s_∞ = inf(蜂巢两值周长律 λ(W)/(6W)→0 为反例)⟹ 单点 λ(2)>0
不给下界;钉扎拼接绕开单调性要求。

## 四、引理 F(T₂p 版翻转对;机制实证)

**引理 F**。设类 c、c′ 满足:
(i) 它们的全部边只邻接两个十二边形 D、D′(即 c、c′ 各为"被 D、D′ 夹住"
的方形的对边类;方形本身无方程);
(ii) D 的两条平衡方程分别以 (∓1, ±1)、(±1, ∓1) 同时含 c、c′(系数相反),
D′ 同构;
(iii) 其余方程不含 c、c′。
则 d = e_c + e_{c′} ∈ ker A ∩ {0,1}^C(翻转对是解),且与任何不涉及
c、c′ 的解独立叠加。∎(逐方程:D、D′ 部分和变化 +1−1 = 0。)

**L=2 实证**(2×2,T₂p 圈 12 边、钉 12 类 P = {0,1,9,10,12,20,21,27,
30,35,43,44}):类 18 = 方形 14 的对边类(边 22、43,邻接 face 4(十二)、
face 7(十二)、face 14(方));类 26 = 方形 17 的对边类;face 4 与 face 7
正是夹住这两个方形的两个十二边形,其方程:

  face 4 eq1: {18:−1, 26:+1, 32:−1, 44:+1}   eq2: {0:+2, 3:−2, 18:+1, 26:−1, ...}
  face 7 eq1: {18:+1, 26:−1, 35:+1, 40:−1}   eq2: {6:−2, 10:+2, 18:−1, 26:+1, ...}

18 与 26 在全部方程中仅于此出现且系数相反 ⟹ d = e₁₈+e₂₆ ∈ ker;
18,26 ∉ P ⟹ 翻转解落在钉扎子集内。34 个解(键控 DP 与逐方程枚举一致)
= 全零 ⊕ d₁₈₂₆ ⊕ 6 个 6-类波(另一族核向量)及其合法叠加。

## 五、构造定理的失效:λ₀*(2) = 0(2026-10-05 终判)

**构造定理(条件版,已被数值否证其前提的可满足性)**:若 2×L 环面的
钉扎圈不碰引理 F 对且对的平移像逐列不交,则 n₀(2,L) ≥ 2^L。**数值终判**:
T₂p 钉扎序列(roundE_4612_pinned_dp_t2p.py,RTH4612_binary_pinned_t2p.csv)
L = 2..14 全部 **n₀″ = 4(常数)**,ln n₀″/L 从 0.693 递减至 0.099,
λ₀*(2) = limsup = 0 ⟹ 拼接判定链**失效**:钉一条绕长向的圈(钉 ~6L 类,
横跨全部行)把 2×L 环面的解空间从 ~2^{2.7L} 压到 O(1)=4(全零、补翻及
两个全局模式)。级联钉扎横贯所有行,行波与列波全灭。

**科学含义(负结果但有结构信息)**:4.6.12 两值解空间虽宽极限熵正
(λ(W) 路线证据),但对圈状缺陷**极端脆弱**——对比蜂巢两值(周长律,
钉圈后仍周长形态,稳健)。解空间的"界面敏感度"在十一网络分类中是一个
此前未分辨的维度:正熵 ⟹̸ 界面稳健。

**判定路线收拢**:拼接定理不构成 4.6.12 的判定工具(不入论文);
两值/三值正熵的判定**完全回归 λ(W) 非谐振递增性数值路线**
(W=3×L=4/5 DP 在跑)。G1 圈对验证(4×2 双圈切双带,分量 48+48)作为
几何引理的验证记录保留——它证明了带切分的几何可行性,失效在熵层面
(钉扎后无解可数),不在几何层面。

**残余构造路线的终判(2026-10-05,roundE_4612_dualavoid.py)**:最后一条
构造性通道 = "双圈避开行波"(若 2×L 环面存在同时避开 T₁p 圈类与 T₂p
圈类的解族 ~2^{cL},宽环面每带独立取避开解 ⟹ 免定理直接构造)。**裁决**:
2×2 与 2×3 的双避解均恰 **2 个**(全零解+补翻解),不随 L 指数 ⟹
通道关闭。全解分类:2×2 的 22 912 解中 22 850 个同时触碰两圈(99.8%),
避开单圈者 46/14——**解空间被任意横贯圈统治**,脆弱性是全局性质而非
特定圈的性质。至此所有构造性证明路线穷尽,正熵判定完全依赖数值路线。

## 六bis、机制对比:4.6.12 的熵若正,如何 survive(与蜂巢对照)

**问题**(2026-10-05 用户):若 4.6.12 存在正度量熵,其 survive 机制与
蜂巢一样吗?**答案:不一样——蜂巢是局域模机制,4.6.12 的全部证据指向
扩展波机制,且后者对圈状缺陷极端脆弱。**

**蜂巢(已确立)**:每六边形一模——每孔携带一个局域形状参数,孔间只经
共享边耦合;约束欠计数(flat band);自由度 = 局域模,钉一个孔只伤局部。

**4.6.12 的证据链**:
1. T₁p 行波族(2^L,每列 1 bit)——"局域 bit"的表象;
2. T₂p 钉扎(横贯所有行的圈)⟹ 解空间 2^{2.7L} → 4:**自由度对横贯
   缺陷不稳健**;
3. L=2 的 34 解结构:1 个局域对 (18,26) + 6 个 6-类扩展波(核向量,
   可部分独立叠加)——自由度的真实载体是**跨列扩展波**;
4. 约束密度分层:方形 0 方程、六边形 2/6 边、十二边形 2/12 边——HD
   扇区约束密度是蜂巢孔方程的一半。

**统一视角(候选机制)**:两系统的解格核(Ax=0 的 {0,1} 向量族)都是
约束图圈空间的推广;正熵 ⟺ 核含指数多的 {0,1} 向量。差异在圈的空间
组织——蜂巢:局域小圈(孔环)的指数组合;4.6.12:局域对 + 扩展波的
指数组合。**可检验预言**:(i) 解族生成元数 ~ cL 线性(L=3 的 64=2⁶
即 6 个生成元,支持);(ii) 任何横贯带的原生边圈钉扎都压平解空间
(T₁p/T₂p 两方向已验证);(iii) 蜂巢钉圈实验应显示稳健(未做,对照
实验候选);(iv) 扩展波的支撑长度 ~ O(列宽) 或更长,可用 L=2..4 解的
支撑直径统计检验。

**分类学定位**:若成立,则十一网络的正熵机制分裂为两型——**局域模型**
(蜂巢 6.6.6、3.4.6.4 的三角形锁死泄漏?)与**扩展波型**(4.6.12),
判据 = 钉扎敏感度(横贯圈钉扎后解数是否指数)。kagome 的条带模是
"扩展波但多项"的反例:扩展 ⟹̸ 指数,指数性需逐系统验证。
