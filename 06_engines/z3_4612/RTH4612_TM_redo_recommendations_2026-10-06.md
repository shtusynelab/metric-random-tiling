## 一、为什么 DP 短链判据失效:3.12.12 的实测教训(本日,已全部对拍验证)

3.12.12(截角蜂窝)今日完成 mid 子系统柱面转移矩阵谱半径 ρ(W) 测量
(`z3_31212/step7_tm.py`),其正确性由 **Tr(T^L) 与精确 DP 逐位对拍**锚定
(k=2 W=2: Tr=64/256/1024;k=3 W=2: Tr=1017/16041,与 frontier DP 精确计数
逐位相等),并由 PF 定理的直接观测闭环(k=3 W=2 的 torus λ(L) 从 1.6015
@L=33 单调爬向 TM 值 1.6094 @L=57,cross.log)。

在这个已验证的 TM 下,三个此前"确凿"的判读全部翻转或失效:

1. **"λ(W) 平坦 ⟹ 周长律/倾向零"是假象**:TM 给出 λ_mid3(W) = 1.609 / 2.012 /
   2.502 / 3.015 / 3.549 / 4.093(W=2..7,**随 W 近线性增长,斜率 ≈0.5**)⟹
   面积律,s_mid3(∞) ≈ 0.17–0.20。而短链 torus DP 的 λ(W) 读数(W=3 全程
   0.693 到 L=11、W=5 到 L=9 等)全是 crossover 前的值。
2. **"精确公式 ⟹ 定律成立"也是假象**:Ω = 2^(L+W+1)(每列 1 bit 传播)在
   W≤4 被验证 17/17 "精确",W=5 到 L=9 仍精确——但它是**次主导特征值 2.0 的
   超大简并瞬态扇区**,crossover 后被主扇区(λ 随 W 增长)淹没。瞬态不仅长,
   还以**精确幂律公式**的形态出现——这正是它连续骗过两轮判读(一次判正、
   一次判负)的原因。
3. **crossover 尺度实测**:k=3 W=2 到 L=57 仍未完全收敛(λ=1.6052,极限
   1.6094);W=3 在 L=11→13 之间破缺(λ 从 0.693 跳向 2.01);k=2 W=5 到
   L=17 仍精确 2 军团。L\*(W) 随 W 急增——**W 越大,可及的 DP 链越深陷
   crossover 之前的区域**,即"宽度越大越测不准",与直觉相反。

对 4.6.12 的含义:**4.6.12 与 3.12.12 同属 z=3 混合面劈行系,机制语法同族
(六边形主导 + 劈行类系统)**。其全部现有 λ(W) 判读——原判定的"W=2..5 带
0.21–0.31 重叠"、3.12.12 会话本日早间审计的"λ(W) 平坦 2.5–3.2 ⟹ s≈0.04 或
0"——都建立在 L≤5(W≥3)/L≤14(W=2) 的短链上,**没有任何一条链被证明过了
crossover**。3.12.12 实测其 W=2 链的"表观渐近"(增量 2.534→2.540,看似收敛)
与真极限差 0.011 且方向在 L=57 处仍未定——4.6.12 的 W=2 序列有完全相同的
签名(2.534→2.540,+0.006/两列)。换言之:4.6.12 的 λ(2)≈2.5 本身就还是
下界读数,宽度行为则完全未知。

## 三、TM 重做方案(方法可移植性)

3.12.12 的 TM 管线(`z3_31212/step7_tm.py`,已验证)对 4.6.12 的适配:

1. **几何/方程源**:4.6.12 的约化类系统已在 `roundE_4612_zcount.build_reduced`
   (SD 3N + SH 3N + HD 6N 类;dodecagon 2 条 SD 平衡方程 + hexagon 2 条
   三系数方程)——方程体系现成且已经过 dim=4N+4 与计数双重验证。
2. **列结构**:沿 A2 方向切柱面成列;每个类标注其所属列(HD 类=六边形对角
   对,取两 edge 列的 min;SH 类=边,取 incident hexagon 列)→ 每列方程的
   槽位映射(prev/current/next),与 3.12.12 的 bucket 分类同构。
3. **状态空间估计(先行侦察)**:4.6.12 的 frontier 宽度可从既有 DP 日志
   (`RTH4612_binary_strips.csv` 的 tree_width/peak_states 列)直读——W=2 的
   peak_states 给出状态数下界;按 3.12.12 经验 reachable ≪ 全空间。预估
   k=2 W=2..4 全可行(状态 ≤~1e6–1e7),k=3 W=2..3 可行,W≥5 视实测。
   fail-closed 闸沿用(状态 2e8 / nnz 2e10)。
4. **验证闸(必做,且是唯一可信门)**:Tr(T^L) 对拍既有精确 DP
   (W=2: Ω(2,2)=22 912、Ω(2,3)=58 240、Ω(2,4)=... 逐位)——**Perron 幂迭代
   "收敛"本身不是门**(3.12.12 调试中污染索引上的幂迭代照样"收敛"出假值,
   是 Tr 对拍抓出的)。
5. **生产与判据**:ρ_2(W)、ρ_3(W) 各 W=2..4(5):
   - λ_2(W) = ln ρ_2(W) 随 W 线性增长(斜率≈6s)⟹ 正熵坐实,s₂ = 斜率/6;
   - 平坦 ⟹ 二值周长律,s₂=0,原 ≥0.21 死;
   - 三值同理(单调性引理兜底连通)。
6. **成本**:实现(列分类+表驱动 DFS 移植)约半天–1 天;W=2..4 生产数小时
   (服务器 140 核,沿用分块 Pool + bincount 幂迭代);合计 1–2 天。

## 四、决策树(三种 TM 结果对应的结论与稿件动作)

| TM 结果 | 结论 | 稿件动作 |
|---|---|---|
| λ₂(W) ∝ W(斜率显著) | 正熵坐实,s₂ = 斜率/6(精确渐近口径);三值同理 | fig1c/S8.2 恢复正熵叙事,但改 TM 口径数值;4.6.12 与 3.12.12 同为载体 |

## 六、3.12.12 TM 实现的四 bug 清单(移植避坑,全部被对拍/断言抓出)

1. 方程系数双乘公因子(2·round(2a),应为 round(2a))——对约束无害但触发
   断言;系数约定先写单测。
2. 桶索引(0–5)与度数键(0/60/…/300)混用——分类表键统一。
3. i=W−1 的表键漏掉 E_{W−2}(W=2 平行边情形暴露)——首末 dodecagon 的
   环绕内部键必须入键。
4. **to_idx 误把列内键编入下一状态索引**——状态空间污染后幂迭代照样
   "收敛",只有 Tr(T^L) 对拍能抓出。**结论:Tr 对拍闸必须是产线第一闸**。
