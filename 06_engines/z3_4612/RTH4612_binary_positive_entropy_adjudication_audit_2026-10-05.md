## 二、口径审计:无 mixing,病在别处

3.12.12 的已改正错误(基线不一致:W=2 用 mid-only、W≥3 用 joint total)
在 4.6.12 **不存在**——DP 条带(`roundE_4612_strip_series.py`)与 Knuth 条带
(`roundE_4612_knuth_strips2.py`)都是同一全约化系统(12N 类)的 total 计数。

真正的病与 3.12.12 改判同型:**宽度论证读的是逐点 s 值(lnΩ/(6WL)),而
W≥3 的链只有 L≤5**——恰是 O(1) 常数 c/(6WL) 托底、谐振振荡最猛的窗口。
逐点 s = λ/(6W) + c/(6WL):在 c ≈ 6–11 的实测背景下(§四),L≤5 的 s 带
0.21–0.31 可以与周长律完全相容。"带间无衰减"是两个小 L 窗口的 c 项互相
托底,不是渐近平台。

## 三、λ(W) 重提取(核心证据;全部出自归档 CSV,判读文档未用此口径)

**W=2 DP 序列(`RTH4612_binary_strips.csv`,L=2..14)逐列增量**:

- 奇→偶相:3.79 / 3.95 / 4.18 / 4.40 / 4.64 / 4.92(上升;谐振扇区振幅增大)
- **两列相位平均:2.360 → 2.458 → 2.589 → 2.626 → 2.658 → 2.679 —— 到 L=14

  L=14 处的读数)。

**Knuth 条带(`RTH4612_knuth_strips2.csv`,hit≥1)非谐振读数**:

| W | λ 实测 | 面积律 s=0.21 要求(λ=1.26W) |
|---|---|---|

**面积律判死**:s=0.21 要求 λ(W=5) = 6.3,实测 3.19——差两倍,与
3.12.12 三值改判同一形态(那里是 2.69 vs 要求 6.75)。

**两种与数据相容的读法**(现有窗口不可分辨):

1. **纯周长律**:λ ≈ 2.5–2.7 恒定;W=3/5 的 +12%/+26% 由小 L 瞬态与相位
   未收敛解释。此时 s_01(∞) = 0,渐近 s(W) = λ/(6W):W=5 处 ≈0.085。
2. **小微面积项**:λ = 6sW + λp 线性拟合(W=2,5):**s ≈ 0.036、λp ≈ 1.67**
   (W=3 预测 2.32 vs 实测 2.85,23% 偏差)。s ≈ 0.036 落在 3.4.6.4 的
   0.031 量级——若成立,4.6.12 不是"thickest binary",而是与 3.4.6.4 同档。

两种读法代数上简并(等效于 lnΩ = λL + gW 与 lnΩ = 6sWL + λpL 的简并),
判别需要:W=3 链延到 L≥8(Knuth 射程边界恰在 L≈5,难)、W=6..8 新宽度、
或三值非谐振条带(§七)。

## 四、"0.21–0.31 平台"为何是假象

逐点 s 分解:s(L) = λ/(6W) + c(W)/(6WL)。用周长律 λ=2.54 反推各宽度常数:
c(3) ≈ 6.3(L=4,5 两点自洽)、c(4) ≈ 8.9(由精确锚 (4,3) 反推)、
c(5) ≈ 10.7–11.4(L=2,3 两点自洽)。c(W) 随 W 近似线性(≈2.3W),这正是
"每宽度边界自由度"型项——它把小 L 的 s 全部托在 0.2 上下,制造了
"W=2..5 平台"的表观。平台是 c 项的镜像,不是渐近。
(原判读文档 §二-D 表的四个"渐近带"全部来自 L≤5 或 L≤10 的逐点 s,
无一到达 λ/(6W) 的渐近。)

## 五、蜂巢二值对照的正确对读(原对比反了)

原判读以"蜂巢二值对照衰减 0.3→0.12(W=2→5),4.6.12 无此衰减"为正熵
论据。核对:蜂巢二值的 0.3/0.12 是**渐近** s(W)(λ ≈ 3.6 恒定 ⟹
s = 3.6/(6W));4.6.12 的 0.21–0.31 是**小 L 逐点** s。若把 4.6.12 也换成
渐近口径,周长律读法给出的 s(W) = 2.54/(6W):W=2 → 0.21、W=5 → 0.085——
**衰减形态与蜂巢二值完全同构**(仅常数不同)。 apples-to-apples 之后,
对照实验从"支持正熵"变为"支持周长律"。

## 六、对角锚与 fig1c 视觉机制(与 3.12.12 同款)

- **固定 W 链在 fig1c 双对数坐标上必然呈斜 1 线**:y = lnΩ ≈ λL + c =
  (λ/(6W))·N_F + c。4.6.12 二值 W=2 系列骑在"平移 slope-1 导线"上,只证明
  λ(2) > 0(即 W=2 处 s ≈ 0.21),不证明 s(∞) > 0——3.12.12 二值有 17 个
  精确点的 λ = ln2 链而 s = 0,同构反例。
- **对角精确锚(3×3, s=0.3007;二值对角 L=1..3 三点拟合 a≈0.44,表观
  s ≈ 0.07)**:对角 = 最大谐振尺寸。3.12.12 的教训直接适用:其对角三点
  a ≈ 0.62 而条带判定 s = 0——对角曲率可以全部是谐振超额。4.6.12 的
  a ≈ 0.44 同样不可当面积律证据。
- 三值四点(L×L 对角,a≈2.05,L=4 斜率 0.81)是全部数据里唯一强弯曲的
  序列——这是三值正熵案例的真正分量,但同样带谐振污染警告,且 L=5 已封账
  (55 万样本 0 命中),无法在环面上延伸。

## 九、教训(入册)

1. **逐点 s 带 ≠ λ(W)**:宽度标度判据必须落在每列增量 λ 上;小 L 逐点 s
   被 c(W)/(6WL) 项托底,天然伪造"平台"。3.12.12(基线混用)与 4.6.12
   (小 L 平台)是同一家族的两种病。
2. **固定 W 链与对角族在双对数图上都不能单独判面积律**:前者恒呈斜 1 线,
   后者带最大谐振超额;判别只能靠 λ(W) 的宽度行为。
3. **"渐近带"措辞纪律**:标注"渐近"前必须确认序列本身收敛(W=2 相位平均
   到 L=14 仍缓升,"收敛至 2.54"即超前陈述)。
4. 对照实验必须同口径(渐近 s(W) vs 小 L 逐点 s 不可比)。
5. 审稿人/用户质疑的价值:本审计由用户对 3.12.12 图的直觉质疑连环触发,
   两处已入稿的正熵判定(3.12.12 三值、4.6.12 二值)均未撑住复核。
